Open source (GPL-3.0) desktop app for playing back Tesla USB dashcam footage. Electron + React + TypeScript. Multi-camera dashcam and Sentry playback synced to within ~2 frames, a live telemetry HUD (speed, G-forces, throttle, lap data) for Track Mode, and a GPS map drawing the full ~45 Hz trace. Everything runs locally; footage never leaves your machine. Windows installer on the Releases page.
